# studia-3semestr

Probability and statistics (MPiS) in the third semester: exercise sets and statistical tables.

University coursework from my Computer Science studies at UWM (2020–2024). The commit history is unchanged. This README was added in November 2026.

Years of work: 2021 (first commit on 16 October 2021, last commit on 20 November 2021).

## Contents

- `06_MPiSa.docx`, `09_MPIS.docx`, `10_11_MPIS.docx`, `12_MPIS.docx`: exercise sets 6, 9, 10–11 and 12, for example density functions and the expected value of a random variable.
- `TABLICE/`: tables of the F, chi-square and Student's t distributions (PDF) and of the standard normal distribution (PNG).

The repository also contains course materials: the exercise sets and the tables above.

## Running

The repository holds documents, not a program, so there is nothing to run.
